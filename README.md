# 翁法罗斯 · AMPHOREUS

> 「泰坦自火中降生，三者开辟天地，三者编织命运，三者捏塑生命，三者引渡灾祸。」

一个以《崩坏：星穹铁道》**翁法罗斯（Amphoreus）** 为主题的单页静态网站。
深空星海 + 无限符号（∞）作为整体背景，收录翁法罗斯世界观简介、**十二位黄金裔**、他们的**光锥卡面**，以及藏在最后的「第十三位」。

当前版本：**v1.0**

---

## 快速开始（VSCode）

1. 用 VSCode 打开本文件夹：`文件 → 打开文件夹… → amphoreus`
2. 推荐安装扩展：**Live Server**（`.vscode/extensions.json` 里已经列好了）
3. 右键 `index.html` → **Open with Live Server**，浏览器会自动打开
   - 默认地址：`http://127.0.0.1:5500`

不想装扩展也可以，任选一种：

```bash
# 方式 A：Python 自带静态服务器
python -m http.server 8123
# 然后访问 http://127.0.0.1:8123

# 方式 B：直接双击 index.html
# 页面可以正常显示（脚本都是本地引入，不走 fetch），推荐还是用服务器
```

## 设计说明

| 元素 | 做法 |
| --- | --- |
| 布局 | 卡片固定 4 / 3 / 2 列（1024px、720px 断点），12 张在任何一个断点都能整除，不会出现半行 |
| 导航 | 滚动时变实底，当前版块自动高亮；右下角回到顶部按钮在 620px 后出现 |
| 宇宙背景 | `canvas` 绘制约 280 颗星，带景深、闪烁、缓慢漂移、鼠标视差，偶尔划过流星 |
| 无限符号 | 首屏居中 SVG，金色渐变描边 + 发光滤镜 + 描边生长动画，另有一圈虚线流光和一个沿路径运行的 `animateMotion` 光点 |
| 配色 | 深空黑蓝 `#05060d` / 黄金 `#e6c88f` / 记忆紫 `#a48cd8`，每位黄金裔另有一套 `--hue` 主色 |
| 卡片 | 3:4.3 竖版角色海报，封面式裁切（保留顶部构图）；悬停上浮、边框发光、图片缓推、高光扫过 |
| 详情 | 点击卡片打开弹层：左侧大图，右侧称号 / 火种 / 城邦 / 题记 / 命运预言 |
| 光锥长廊 | 横向滚动 + scroll-snap，鼠标滚轮或拖拽滚动 |
| 第十三位 | 3D 翻转卡，正面是「未被写下的名字」，点击翻面揭示昔涟 |
| 性能 | 图片全部 `webp` + `loading="lazy"`；`prefers-reduced-motion` 时关闭所有动画 |

响应式断点：`820px`（弹层改单列）、`520px`（黄金裔网格两列）。

## 内容与文案来源

- 世界观、十二泰坦、黄金裔称号与**命运预言**、光锥名称：参考《崩坏：星穹铁道》官方设定及 **BWIKI**（`wiki.biligame.com/sr`）整理。
- 光锥卡面：取自 BWIKI 光锥图鉴立绘，仅用于同人展示。
- 每位角色的题记尽量使用官方卷首语/介绍文案，其余为整理后的叙述，未虚构台词。

## 换图 / 加人

**替换某位的光锥图**：直接覆盖 `assets/lightcones/<id>.webp` 即可，同名即可生效。
**替换某位在卡片上的海报**：覆盖 `assets/heirs/<id>.webp`（建议 744×1211 竖图）。
`id` 与角色对应：

| id | 角色 | 光锥 |
| --- | --- | --- |
| `aglaea` | 阿格莱雅 | 将光阴织成黄金 |
| `tribbie` | 缇宝 | 如果时间是一朵花 |
| `mydei` | 万敌 | 血火啊，燃烧前路 |
| `castorice` | 遐蝶 | 让告别，更美一些 |
| `anaxa` | 那刻夏 | 生命当付之一炬 |
| `hyacine` | 风堇 | 愿虹光永驻天空 |
| `cipher` | 赛飞儿 | 谎言在风中飘扬 |
| `phainon` | 白厄 | 黎明恰如此燃烧 |
| `hysilens` | 海瑟音 | 海洋为何而歌 |
| `cerydra` | 刻律德菈 | 金血铭刻的时代 |
| `evernight` | 长夜月 | 致长夜的星光 |
| `danheng` | 丹恒·腾荒 | 纵然山河万程 |
| `cyrene` | 昔涟（第十三位） | 爱如此刻永恒 |

**新增角色**：在 `js/data.js` 的 `heirs` 数组里追加一项，字段照抄现有结构即可，页面会自动渲染卡片与长廊项。图片缺失时会自动回退为「∞ + 光锥」的渐变占位，不会破版。
